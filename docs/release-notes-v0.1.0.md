# Reopen 0.1.0 Release Notes

Reopen 0.1.0 is the first V1-ready build.

## Highlights

- Menu bar workspace launching.
- Create, edit, duplicate, delete, and reorder workspaces.
- Launch apps, files, folders, URLs, terminal commands, and VS Code projects.
- Best-effort window layout restore.
- Permission onboarding for Accessibility, Automation, and file access.
- Settings for launch behavior, terminal safety, preferred tools, import/export, and reset.
- JSON import/export with duplicate ID repair and import summaries.
- Local diagnostic logs without terminal command output by default.

## Known Limits

- Window layout restore is best-effort and depends on macOS Accessibility support in each app.
- Notarization requires the release maintainer's Apple credentials.
