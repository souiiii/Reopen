# Download Reopen

## Direct Download

The V1 release is distributed as a signed and notarized `.dmg`.

## Install

1. Open the downloaded `.dmg`.
2. Drag Reopen into Applications.
3. Launch Reopen.
4. Use the menu bar icon to create your first workspace.
