# Implementation Plan: Reopen — macOS Workspace Rehydrator V1

Assumed tech stack:

* **Language:** Swift
* **UI:** SwiftUI + AppKit where needed
* **App type:** macOS menu bar app
* **Storage:** Local JSON files
* **Permissions:** Accessibility, Automation, File access
* **Distribution:** Direct download `.dmg`, not Mac App Store for V1

The goal of V1 is:

> A professional macOS menu bar app that lets users create workspaces and launch apps, files, folders, URLs, terminal commands, VS Code projects, and basic window layouts in one click.

A completely bug-free app can never be guaranteed, but this plan is structured to reach a stable, polished, production-quality V1.

Example:

```json

  "name": "Coding",
  "actions": [

    { "type": "openURL", "url": "https://github.com" },
    { "type": "terminalCommand", "command": "npm run dev", "workingDirectory": "/Users/me/Projects/App" }

}
```
